# Terminal Settings 1.10.0 — Preview 1 (Build 19)

This preview makes Advanced power settings read-only inside the app, adds deferred process restarts and persistent reminders, and improves drafts, notices, and keyboard access. It includes English, Simplified Chinese, and Spanish.

**Spanish translations have not yet been reviewed by a native speaker.**

## Changes

- **Power settings use Terminal commands.** The app reads `ttyskeepawake`, `proximitywake`, and `acwake` without elevation and offers fixed commands to copy. It never requests administrator authorization, starts a privileged helper, or writes power settings. Run copied commands yourself in Terminal, then choose **Refresh Status**. These external changes are not part of in-app Undo; an off command explicitly writes `0`.
- **Earlier power records require manual recovery.** A power Undo record or unfinished power journal from an earlier build is never replayed. The Advanced page shows commands that restore each recorded power source. **Check Again** reads the state before removing a restored record. A fully applied change can instead be kept explicitly; partial or conflicting states keep an unfinished journal and its write lock.
- **Dock and Finder restarts wait appropriately.** Dock restarts once, three seconds after the last relevant change; **Later** postpones it. Finder restarts only when requested, because relaunching it can interrupt a copy. Quitting during an active Dock countdown restarts Dock immediately. Postponed Dock and Finder reminders survive relaunch; every restored reminder waits for a click. **Restart Now** is unavailable during a write or refresh. Completion of one restart preserves other in-flight and newly pending reminders.
- **Notices distinguish partial outcomes.** Retained journals or unconfirmed persistence produce persistent warnings. Success notices accumulate six seconds of non-hovering reading time. Enabling VoiceOver cancels automatic dismissal for that notice, even after VoiceOver is disabled. Old or cancelled timers cannot dismiss a newer notice. These timing rules have deterministic test coverage; running-app acceptance is still outstanding below.
- **Keyboard access and clearer rows.** **⌘1–⌘9** select categories, **⌘R** refreshes status, and **⌥⌘Z** undoes the last system change; **⌘Z** remains text-editing Undo. **Restore This Page** is labeled beside the category title and still asks for confirmation. Badges and current values wrap, choice menus allow more width, and an unverified macOS version is noted once per page.
- **Refresh preserves useful editing state.** Reads after a transaction retain the last displayed status while refreshing. Unapplied text drafts survive unrelated refreshes; explicit Apply, Restore, and Undo resynchronize the affected fields. Numeric drafts remain separate from current values. Expanding editors, changing drafts, or loading current values does not itself apply them; feature switches can still submit their selected custom draft, as described in the usage guide.

## Validation and distribution limits

Automated contracts cover the notice timing policy, old Undo/WAL decoding and power-record recovery decisions, restart metadata validation, reopening reminders, writes in flight, and completion of queued restarts. These checks use controlled dependencies and do not establish visible system effects. The package manifest describes static archive checks; it does not independently establish binary/source correspondence or runtime acceptance.

- **Physical pointer-hover timing and VoiceOver have not been accepted in the running app.** Deterministic timing tests do not verify actual hover events, spoken announcements, or VoiceOver activation/deactivation in the shipped interface.
- Spanish remains a preview translation without native-speaker review.
- Local package validation is performed on macOS 26.6.2 (25G83), using Swift 6.3.3 and the macOS 26.5 SDK. The final verification record distinguishes automated checks from isolated GUI smoke checks.
- The package is **Apple silicon arm64** with a **macOS 14.0 deployment target**. No Intel build is supplied, and real macOS 14 runtime acceptance is not claimed.
- Distribution uses **Hardened Runtime and ad-hoc signing**, with **no Developer ID signature or Apple notarization**. Gatekeeper acceptance is not claimed.
- There is no automatic updater. Quit the previous app, verify `TerminalSettings.zip` against `SHA256SUMS`, and replace the extracted app manually. Preserve recovery records while any transaction remains unresolved.
- Previous preview tags, Release attachments, and historical validation reports remain unchanged.

### 主要变更

- **电源设置通过终端修改。** 应用无需提权即可读取 `ttyskeepawake`、`proximitywake`、`acwake`，并提供固定的可复制命令。应用本身不请求管理员授权、不启动特权 helper、不写入电源设置。命令需由用户在「终端」中运行，然后点击**刷新状态**。这些应用外更改不进入应用内 Undo；关闭命令会明确写入 `0`。
- **旧版电源记录须人工恢复。** 早期版本留下的高级 Undo 或未完成事务日志不会被重放。高级页面展示按电源来源恢复旧值的命令，点击**重新检查**后才按实际状态清理记录。完整的更改后状态可由用户明确选择保留；部分写入或外部冲突不会解除未完成日志的写入锁。
- **重启合并与提醒持久化。** Dock 在最后一次相关更改三秒后合并重启一次，可点**稍后**推迟；Finder 仅在用户点击重启时执行，以免中断拷贝。应用在 Dock 倒计时期间退出会立即重启 Dock。已推迟的 Dock 和 Finder 提醒会保留到下次启动，恢复的提醒均等待手动确认。写入或刷新期间不能点击**立即重启**；一项重启完成不会清除其他正在执行或新产生的提醒。
- **通知、快捷键与行布局。** 未清理日志或未确认持久化等部分结果使用持续警告；成功通知累计六秒非悬停阅读时间。通知期间启用 VoiceOver 会永久取消该通知的自动关闭，之后关闭 VoiceOver 也不会恢复倒计时。旧任务不能关闭新通知。**⌘1–⌘9** 切换分类、**⌘R** 刷新、**⌥⌘Z** 撤销上次系统更改；**⌘Z** 仍用于文本编辑。**恢复本页设置**位于分类标题旁并保留确认。行徽章和当前值可换行，菜单加宽，系统版本未验证提示集中到每页。
- **刷新与草稿修复。** 事务后的读取保留原显示状态，尚未应用的文字草稿不会被无关刷新覆盖；明确的应用、恢复和撤销会重新同步受影响的输入框。数值草稿与系统当前值继续分开，展开、编辑或载入草稿本身不应用设置；开启某些功能时仍可能提交选中的自定义草稿，具体入口见使用说明。
