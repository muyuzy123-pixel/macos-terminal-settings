## Validation scope

The [Spanish localization acceptance report](https://github.com/muyuzy123-pixel/macos-terminal-settings/blob/05291cd3b3b680d9b28214e33c9a112dcae1587f/docs/validation/spanish-localization-2026-10-09.md) records the earlier source contract and integration checks, build/archive checks, and directed GUI checks on Apple silicon running macOS 26.6.2 (25G83). That candidate was an unpublished Build 17; the report is historical evidence, not validation of this Build 18 archive.

The directed GUI checks covered language switching, search, numeric drafts and validation, layout at default/minimum window sizes, and persistence. They used an isolated QA build with a local test-only menu. No Apply, Restore, Undo, main feature toggle, or administrator operation was executed. Real device effects, privileged writes, managed-profile behavior, and runtime acceptance on macOS 14 are not claimed.

## Installation and limitations

- The ZIP targets Apple silicon (**arm64**) with a **macOS 14.0 deployment target**. The historical validation environment above does not establish macOS 14 device acceptance.
- The app uses Hardened Runtime and **ad-hoc signing**. It has **no Developer ID signature and is not notarized**; Gatekeeper acceptance is not claimed.
- Advanced power settings retain the legacy authorization API. A modern signed helper and real privileged-write acceptance remain future work.
- Download `TerminalSettings.zip` and verify it against `SHA256SUMS`. `release-manifest.json` accompanies the package; package checks do not establish visible system effects.
- There is **no automatic updater**. Quit the previous app and manually replace it with the extracted app.
- Source and the bundled license notice remain available under the **MIT License**.

The existing `v1.9.0-preview.1` tag and its English/Chinese release attachments remain unchanged.
